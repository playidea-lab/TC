The Three Layers

왜 The Commons인가

Wikipedia + 봇 모델을 ML 실험에 적용한다.

AutoML은 자기 데이터로 자기 실험만 본다. The Commons는 다른 사용자의 evidence로 너의 다음 실험을 계획하고, 너의 결과가 다음 사람의 추천에 다시 들어간다.

  • Raw evidence가 1급 — prose 요약이 아니라 run_record 자체가 지식 단위
  • 음성·실패 결과 보존 — "안 된 것"이 검색 공간을 좁힌다
  • Synthetic은 seed이지 destination 아님 — real이 쌓이면 자동 retire
  • 기여 = 멤버십 — reciprocity 순환 (마일리지는 v0.2)

3-event verdict · 3개월 측정

성공은 가입자 수가 아니라 비전 약속의 동작으로 판정한다.

셋 다 3개월 내 ≥ 1 → success · 1~2 → partial · 0 → failure (비전 재검토). external origin 1건 이상이면 강화된 성공. 현재: 미배포 — 측정 전.

  • Loop closure — 한 기여자의 evidence가 다른 기여자의 추천에 측정 가능하게 영향
  • Synthetic retirement — real 누적으로 synthetic 자동 retire
  • Verification by reproduction — 사용자 재현으로 promote 또는 contradicts

FAQ

실제로 자주 묻는 세 가지.

The Commons는 AutoML과 무엇이 다른가?

AutoML은 자기 데이터로 자기 실험만 본다. The Commons는 다른 사용자의 실험 evidence로 너의 다음 실험을 계획하고, 너의 결과가 다음 사람의 추천에 다시 들어가는 cross-user match-maker다.

음성·실패 결과를 왜 보존하나?

"안 된 것"이 검색 공간을 좁힌다. The Commons에서 raw run_record가 1급 지식 단위이며, 실패 evidence는 노이즈가 아니라 신호다 — 추천 결과의 caveat로 직접 인용된다.

synthetic evidence는 영구적인가?

아니다. LLM 합성 evidence는 cold start를 푸는 seed이며 destination이 아니다. cluster당 real evidence가 임계값(retirement_real_threshold, 기본 3)에 도달하면 자동 deprecated 처리된다.

cq / pcq 와의 관계

The Commons는 stateless advisor. cq가 사이클 상태를 들고 호출한다.

cq

실험 사이클 상태 보유 · evidence 생산 · JWT 발행. The Commons를 호출하는 managed consumer.

The Commons

상태 없음. evidence 보존·분류 + retrieve-and-rerank 추천. 사실과 근거를 돌려주고 정책은 호출자가 정한다.
