The Commons

An open library + match-maker of agent-readable ML experiment evidence.

pcq writes the books. cq prints them.
The Commons keeps them — and tells you which to read next.

Internal stakeholder status — v0.1 / 코드 안정화 완료, 운영 배포 대기. 최종 갱신: 2026-05-18.

The Three Layers

pcq — Format (the book)
ML 실험 evidence의 Apache-2.0 contract. pcq 2.x: intent 3필드 + data fingerprint + synthetic 표식.
↓ books are written
cq — Press (the printing house)
분산 GPU·큐·대시보드·에이전트 루프. evidence를 생산하고 The Commons로 운반.
↓ books arrive
The Commons — Library + Match-maker (this project)
evidence 보존 · 분류 · 검색 + "이 문제 + 이 리소스 → 추천 recipe". 음성·실패 결과도 1급 자산.

왜 The Commons인가

AutoML은 자기 데이터로 자기 실험만 본다. The Commons는 다른 사용자의 실험 evidence로 너의 다음 실험을 계획하고, 너의 결과가 다음 사람의 추천에 다시 들어간다 — Wikipedia + 봇 모델을 ML 실험에 적용한 cross-user matchmaker.

  • Raw evidence가 1급 — prose 요약이 아니라 run_record 자체가 지식 단위
  • 음성·실패 결과 보존 — "안 된 것"이 검색 공간을 좁힌다
  • Synthetic은 seed이지 destination 아님 — LLM 합성 evidence가 cold start를 풀고, real이 쌓이면 자동 retire
  • 기여 = 멤버십 — reciprocity 순환 (마일리지는 v0.2)

3-event verdict (3개월 측정)

v0.1 성공은 가입자 수가 아니라 비전 약속의 동작으로 판정:

  • Loop closure — 한 기여자의 evidence가 다른 기여자의 추천에 측정 가능하게 영향
  • Synthetic retirement — real 누적으로 synthetic 자동 retire
  • Verification by reproduction — 사용자 재현으로 promote 또는 contradicts

셋 다 3개월 내 ≥ 1 → success · 1~2 → partial · 0 → failure (비전 재검토). external origin 1건 이상이면 강화된 성공. 현재: 미배포 — 측정 전.
